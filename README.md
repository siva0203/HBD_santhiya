# Santhiya birthday site

Structure:
  index.html            the chat-style birthday page (locked until Dec 10, 2026)
  adventure/            put your adventure website here (index.html inside)

## Host on GitHub Pages (free)
1. Create a repo, upload everything in this folder (keep the structure).
2. Repo Settings > Pages > Deploy from branch > main > /(root) > Save.
3. Your site: https://USERNAME.github.io/REPO/
   Adventure:  https://USERNAME.github.io/REPO/adventure/

## Things you can change in index.html
- Unlock date: search for 2026-12-10T00:00:00+05:30
- Adventure link: search for  var ADV='adventure/';
  (use a full https:// link if the adventure lives elsewhere)
- Preview before the birthday: add ?open to the address, or tap the heading 5 times.
